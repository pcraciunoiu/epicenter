# Whispering v7.12.0-alpha.5

Unofficial alpha release for Linux testing on [pcraciunoiu/epicenter](https://github.com/pcraciunoiu/epicenter).

## Highlights

- **Fix MPRIS stacking for real:** defer `<audio src>` until the user presses play (`LazyAudio`). Eager `src` updates after each PTT save were registering stacked `org.webkit.*` MPRIS players; `enable-media-session=false` alone was not enough on this WebKitGTK.
- Web Audio UI beeps (alpha.3) + best-effort WebKit media-session disable (alpha.4) kept as defense in depth

## Install

```bash
wget https://github.com/pcraciunoiu/epicenter/releases/download/v7.12.0-alpha.5/Whispering_7.12.0-alpha.5_amd64.deb
sudo dpkg -i Whispering_7.12.0-alpha.5_amd64.deb
sudo apt-get install -f
```
