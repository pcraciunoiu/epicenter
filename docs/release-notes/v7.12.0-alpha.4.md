# Whispering v7.12.0-alpha.4

Unofficial alpha release for Linux testing on [pcraciunoiu/epicenter](https://github.com/pcraciunoiu/epicenter).

## Highlights

- Disable WebKitGTK `enable-media-session` on Linux so the home-page recording `<audio>` no longer stacks GNOME MPRIS media-player cards after each PTT save
- UI feedback sounds via Web Audio (from alpha.3)
- Linux PTT via evdev listener + `~/.config/whispering/ptt.conf`

## Install

```bash
wget https://github.com/pcraciunoiu/epicenter/releases/download/v7.12.0-alpha.4/Whispering_7.12.0-alpha.4_amd64.deb
sudo dpkg -i Whispering_7.12.0-alpha.4_amd64.deb
sudo apt-get install -f
```
