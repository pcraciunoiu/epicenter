# Whispering v7.12.0-alpha.1

Unofficial alpha release for Linux testing on [pcraciunoiu/epicenter](https://github.com/pcraciunoiu/epicenter).

## Highlights

- Linux `.deb` build workflow for fork releases (`publish-whispering-linux-deb.yml`)
- Global shortcut defaults on Linux: PTT `F14`, toggle `F13`
- `WHISPERING_PTT_KEY` and `WHISPERING_TOGGLE_KEY` env vars for the app and evdev listener
- `scripts/linux/whispering-start.sh` to launch Whispering with the shortcut listener

## Install

```bash
wget https://github.com/pcraciunoiu/epicenter/releases/download/v7.12.0-alpha.1/Whispering_7.12.0-alpha.1_amd64.deb
sudo dpkg -i Whispering_7.12.0-alpha.1_amd64.deb
sudo apt-get install -f
```

## Linux shortcuts

```bash
export WHISPERING_PTT_KEY=F14
export WHISPERING_TOGGLE_KEY=F13
~/.local/bin/whispering-start.sh
```

See `apps/whispering/docs/linux-dev-setup.md` for Moonlander, keyd, and systemd setup.
