# Whispering v7.12.0-alpha.6

Unofficial alpha release for Linux testing on [pcraciunoiu/epicenter](https://github.com/pcraciunoiu/epicenter).

## Highlights

- **Manual dictation segments:** optional Manual-mode toggle that uses VAD to commit finished phrases through the normal save → transcribe → deliver pipeline (PTT unchanged)
- Segments ON uses the Voice Activated recorder path (`getUserMedia` / WebView mic); device picker switches to the VAD selector
- Linux WebKitGTK: auto-allow UserMedia/DeviceInfo permissions for segments
- VAD sensitivity: lower speech thresholds + ×2 software gain before MicVAD; AGC / echo / noise constraints enabled

## Install

```bash
wget https://github.com/pcraciunoiu/epicenter/releases/download/v7.12.0-alpha.6/Whispering_7.12.0-alpha.6_amd64.deb
sudo dpkg -i Whispering_7.12.0-alpha.6_amd64.deb
sudo apt-get install -f
```
