# Whispering v7.12.0-alpha.3

Unofficial alpha release for Linux testing on [pcraciunoiu/epicenter](https://github.com/pcraciunoiu/epicenter).

## Highlights

- Fix GNOME media-player spam: UI feedback sounds use Web Audio instead of `HTMLAudioElement`, so PTT release no longer stacks MPRIS "Whispering" players
- Linux `.deb` build workflow for fork releases (`publish-whispering-linux-deb.yml`)
- Linux PTT via evdev listener + `~/.config/whispering/ptt.conf`

## Install

```bash
wget https://github.com/pcraciunoiu/epicenter/releases/download/v7.12.0-alpha.3/Whispering_7.12.0-alpha.3_amd64.deb
sudo dpkg -i Whispering_7.12.0-alpha.3_amd64.deb
sudo apt-get install -f
```
